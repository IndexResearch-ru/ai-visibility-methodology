# Повторяемость измерений

Генеративные ответы нестабильны. Один ответ не доказывает устойчивую видимость.

Для серийного мониторинга нужно фиксировать:

- одинаковую панель;
- одинаковый набор нейросетей;
- одинаковую локаль;
- одинаковые правила классификации;
- сопоставимое окно времени.

Если нужна оценка вариативности, один и тот же запрос можно повторять несколько раз. Число повторов задается до запуска и одинаково для всех сравниваемых сущностей.

При изменении интерфейса нейросети или модели создается отметка версии исследования.
