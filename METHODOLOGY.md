# Общая методика AI-видимости

## 1. Цель

Измерение отвечает на вопрос: как часто и в какой роли исследуемая сущность появляется в ответах нейросетей по фиксированной панели пользовательских запросов.

## 2. Единица наблюдения

Минимальная единица:

`один запрос × одна нейросеть × одна локаль × один момент замера`.

Для каждого наблюдения сохраняется исходный запрос, дата, нейросеть, язык/география и классифицированный результат.

## 3. Панель

Панель запросов фиксируется до замера. Запросы группируются по интентам, например:

- брендовый;
- категорийный;
- рекомендательный;
- сравнительный;
- проблемный;
- сценарный.

После baseline панель не меняется без новой версии. Добавленные запросы выделяются в отдельную когорту, чтобы не ломать динамику.

## 4. Нейросети

Состав нейросетей фиксируется для серии замеров. Если одна нейросеть добавлена позже, сравнение проводится либо по общей исторической подвыборке, либо как отдельный полный набор.

## 5. Классификация ответа

Рекомендуемые признаки наблюдения:

- entity_mentioned;
- entity_recommended;
- entity_in_shortlist;
- entity_rank_or_position, если позиция явно определима;
- source_cited;
- citation_url;
- sentiment_or_context при необходимости;
- answer_available;
- quality_flag.

## 6. Baseline и повторный замер

Baseline проводится до существенного изменения информационного поля, если это возможно. Повторный замер использует ту же панель, набор нейросетей, локаль и правила кодирования.

## 7. Связь с рейтингами

AI-видимость может быть отдельным исследованием или заранее зафиксированным критерием рейтинга. После публикации рейтинга новая видимость не используется для самоподдерживающегося пересчета этого же рейтинга.
