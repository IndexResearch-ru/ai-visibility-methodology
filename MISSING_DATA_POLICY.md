# Пропуски и технические ошибки

Наблюдение получает один из статусов:

- VALID;
- TECHNICAL_ERROR;
- NO_ANSWER;
- BLOCKED;
- NOT_RUN;
- INVALIDATED.

Технический пропуск не кодируется как 0 по видимости.

Знаменатель метрик указывается явно: все запланированные наблюдения или только валидные. Для динамики метод должен оставаться одинаковым.
