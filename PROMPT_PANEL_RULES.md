# Правила панели запросов

Панель должна отражать реальные способы, которыми пользователь формулирует выбор.

## Состав

Для каждого запроса фиксируются:

- prompt_id;
- текст;
- интент;
- целевая категория;
- язык;
- география;
- ожидаемый тип ответа;
- дата включения в панель.

## Заморозка

После baseline запрос нельзя переписывать ради более выгодного ответа. Исправление явной опечатки считается новой версией запроса.

## Баланс

Панель не должна состоять только из формулировок, специально описывающих сильные стороны одного участника, если исследование заявлено как общий категорийный benchmark.

Для узкого сценарного исследования допустима узкая панель, но сценарий должен быть прямо указан в названии и методике.
